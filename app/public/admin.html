Atelier pour Windows

L’application prépare les chansons sur votre PC, avec sa carte graphique NVIDIA, puis les envoie à ce serveur. Au premier lancement, elle installe ses outils d’IA (environ 8 Go).

Code de liaison

À coller dans l’application au premier lancement (ou menu Réglages → Serveur en ligne).

Mise en route

  1. Placez DtForget-Atelier.exe dans un dossier à vous (ses données seront créées à côté).
  2. Lancez-le. Windows peut demander une confirmation : « Informations complémentaires », puis « Exécuter quand même ».
  3. Collez le code de liaison, puis laissez l’installation se terminer.
